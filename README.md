# RoAGt drafts A

Static execution directory for A1–A17. Each execution has buttons to open its viewer, classification, and timestamp log in a new tab.

Website: https://oussamanahnah.github.io/RoAGt_drafts_A/

## Hosting

The GitHub Pages workflow publishes the repository on pushes to `main`. In repository **Settings → Pages**, select **GitHub Actions** as the source if Pages has not already been enabled. You can then rerun the **Deploy static content to Pages** workflow from the Actions tab.

All page links are relative so the site works under the repository's GitHub Pages path. The index requires no build tools or external dependencies.
